# Session 3 Assignment: Functions & Data Structures

This project is a comprehensive Python script developed for the **Data Analysis** course. It demonstrates the use of reusable functions, manipulation of various Python data structures (Lists, Tuples, Sets, Dictionaries), and advanced concepts like Lambda functions and error handling.

## 🚀 Features

### Part A: Basic Functions
* **User Greeting:** A personalized greeting function.
* **List Management:** Functions to perform basic operations (Add, Remove, Display) on numerical lists.

### Part B: Data Structures & CRUD
* **Collection Handling:** Demonstrates differences between Lists, Tuples, and Sets.
* **Nested Structures:** Manages a student database using a dictionary where values are lists of scores.
* **Analytics:** A function to calculate and display average scores from nested data.

### Part C: Advanced Logic
* **Lambda Functions:** Anonymous functions used for mathematical squaring and filtering even numbers.
* **List Comprehension:** Efficiently processing data using functional programming techniques.

### 🧮 Bonus: Robust Calculator
* **Multi-functional:** Supports `+`, `-`, `*`, `/`, `%`, and `**`.
* **Dictionary Mapping:** Uses a dispatch table (dictionary) to map operators to functions instead of bulky if-else blocks.
* **Error Handling:** Implements `try/except` blocks to catch `ValueError` and `ZeroDivisionError`.
* **History Log:** Tracks all calculations performed during the session.

## 🛠️ Data Structures Comparison

| Structure | Mutable | Unique Elements | Key Use Case |
| :--- | :---: | :---: | :--- |
| **List** | Yes | No | Ordered collections, dynamic arrays |
| **Tuple** | No | No | Fixed data, coordinates, dictionary keys |
| **Set** | Yes | Yes | Removing duplicates, membership testing |
| **Dictionary**| Yes | Keys only | Storing mapped relationships (JSON-like) |
